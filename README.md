# Recursos · Criandos-Sites

Uma biblioteca enxuta de links e referências para criar sites, sistemas e automações.

## Categorias

- [IA](ia/README.md) — Ferramentas, prompts e práticas de inteligência artificial.
- [Desenvolvimento](desenvolvimento/README.md) — Web, arquitetura, linguagens, testes e ferramentas de desenvolvimento.
- [Design](design/README.md) — Interfaces, experiência do usuário, acessibilidade e identidade visual.
- [WordPress](wordpress/README.md) — Temas, plugins, desempenho e manutenção de sites.
- [APIs](apis/README.md) — Documentação, integrações e boas práticas de consumo de APIs.
- [Automação](automacao/README.md) — Fluxos, integrações e tarefas repetitivas.
- [Aprendizado](aprendizado/README.md) — Cursos, trilhas, tutoriais e materiais de estudo.

## Comece aqui

Escolha uma categoria e leia suas orientações. As pastas começam como espaços de contribuição; ainda não há um catálogo de itens validados.

Para cadastrar um recurso, use o [modelo de recurso](templates/recurso.md) e adicione uma entrada no README da categoria.

Leia [como contribuir](CONTRIBUTING.md). Sugestões e correções também podem ser enviadas pelas issues.
